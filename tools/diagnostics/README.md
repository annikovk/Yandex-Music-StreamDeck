# Сбор диагностики DOM Яндекс Музыки (Windows)

Этот скрипт нужен, чтобы понять, почему на конкретной странице Яндекс
Музыки кнопки Stream Deck не работают. Он раз в секунду снимает DOM
страницы и сохраняет каждый снимок в JSON-файл.

## Что внутри
- `dump-ym-dom.bat` — двойной клик, запускает сбор.
- `dump-ym-dom.ps1` — собственно скрипт (вызывается из `.bat`).
- `dom-dumps/` — сюда будут складываться снимки (папка создастся
  автоматически при первом запуске).

## Как пользоваться

1. **Запусти Stream Deck.** Убедись, что плагин Yandex Music уже
   стартанул Яндекс Музыку (приложение должно быть открыто). Плагин
   запускает приложение с флагом отладки `--remote-debugging-port=9339`,
   именно к этому порту скрипт и подключается.

2. **В Яндекс Музыке открой ту страницу, на которой кнопки не работают.**
   Например, **My Vibe / Моя Волна**.

3. **Двойным кликом запусти `dump-ym-dom.bat`.** Откроется консоль и
   начнётся сбор. Каждую секунду в папку `dom-dumps/` будет падать новый
   файл `dump-YYYYMMDD-HHMMSS-fff.json`.

4. **Прямо во время сбора** попробуй нажать кнопки на Stream Deck (или
   соответствующие кнопки в самом приложении: play/pause, like, mute,
   next, previous). Это нужно, чтобы в снимках было видно, как DOM
   меняется при действиях.

5. **Через 30–60 секунд (или дольше) останови сбор: `Ctrl+C` в окне
   консоли**. Скрипт скажет, сколько снимков собралось и где они лежат.

6. **Заархивируй папку `dom-dumps/` в ZIP** и отправь архив обратно.

## Если что-то пошло не так

- **«cannot reach Chrome DevTools Protocol on port 9339»** — значит,
  Яндекс Музыка не запущена через плагин. Запусти Stream Deck, дай ему
  пару секунд стартовать приложение, и попробуй снова.
- **«no music-application page target found»** — порт открыт, но это
  не Яндекс Музыка. Скорее всего, приложение запущено вручную без флага
  отладки. Закрой его полностью и дай плагину перезапустить.
- **Windows ругается на PowerShell-скрипт** — это нормально, `.bat`
  обходит ограничения через `-ExecutionPolicy Bypass`. Просто запускай
  `.bat`, не сам `.ps1`.
- **Файлы получаются большими (1–3 МБ каждый)** — это ожидаемо, в них
  лежит полный HTML страницы. Архив всё это сожмёт раз в 5–10.

## Что в каждом снимке

```jsonc
{
  "timestamp": "2026-05-13T18:42:10.123Z",
  "url": "music-application://desktop/",
  "title": "Яндекс Музыка",
  "viewport": { "w": 1280, "h": 720 },
  "testIds": [
    // Каждый элемент с data-test-id — тег, классы, позиция, sprite-ссылки,
    // aria-атрибуты, обрезанный textContent
  ],
  "playerBarCandidates": [
    // Кандидаты на «плеер-бар» по подстрокам в class
  ],
  "html": "<html>... весь DOM ...</html>"
}
```

Информации в `testIds` и `playerBarCandidates` обычно хватает, чтобы
понять, по каким селекторам теперь искать кнопки на новой странице.
